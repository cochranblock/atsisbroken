## Visual Hierarchy (TUI)

| Element            | Current                                              | Assessment |
|--------------------|------------------------------------------------------|------------|
| App title          | Bold `atsisbroken` left-edge of header               | ✓ Clear |
| Version            | Dim, immediately after title                         | ✓ De-emphasized |
| Mode badge         | `mode: <mode>` right side, accent on the value       | ✓ Glanceable |
| Queue depth        | `queue: N events` right side, dim                    | ✓ Quantitative |

## Layout & Spacing (TUI)

| Area                  | Constraint                          | Note |
|-----------------------|-------------------------------------|------|
| Header                | `Length(1)` row, 50/50 horizontal   | left = title, right = status |
| Tab bar               | `Length(1)`                         | inline `•` separators |
| Gutter                | `Length(1)` empty                   | breathing room before body |
| Body                  | `Min(1)`                            | absorbs remaining height |
| Footer                | `Length(1)`                         | hints, no border |
| Profile field gutter  | `{label:24}` padded, then `value`   | values left-align across rows |
| Queue row             | `<idx>  <marker>  <label>  → <key>` | columnar |

The 1-row footer with **no `Borders::TOP`** is deliberate — a TOP
border on a 1-row chunk consumes the row entirely and hints
disappear. Whitespace + dim styling carry the visual weight. Found
and fixed during the gate; the `render_html_includes_keybind_footer_hints`
test now guards against regression.

## Interactivity Cues (TUI keybindings)

| Action                  | Keys                          | Cue |
|-------------------------|-------------------------------|-----|
| Quit                    | `q`, `Esc`, `Ctrl-C`          | accent `q` in footer |
| Next tab                | `Tab`, `→`, `l`               | active tab underlined + accent |
| Prev tab                | `Shift-Tab`, `←`, `h`         | mirror |
| Jump to tab N           | `1` / `2` / `3`               | accent `1/2/3` in footer |
| Cycle mode              | `m` / `M`                     | accent `m`; mode badge updates |
| Scroll down (queue)     | `↓`, `j`                      | accent `j/k` in footer |

Vim users, arrow-key users, and digit users are all served. No mouse
required, no mouse supported (terminal-portable across SSH, tmux,

## Cross-Strategy Consistency (CLI fall-through)

The strategy ladder lets the user fall through tiers when CDP isn't
reachable. Every tier must surface its outcome consistently.

| Strategy        | Stdout shape                              | Exit | Hint on failure? |
|-----------------|-------------------------------------------|------|------------------|
| `cdp-attach`    | "CDP attached — N tab(s):" + list         | 0    | ✓ "Launch Chrome with --remote-debugging-port..." |
| `cdp-launch`    | "cdp-launch not yet wired — fall through" | 0    | ✓ falls through to userscript |
| `extension`     | "extension is installed; run `bridge`"    | 0    | ✓ |
| `userscript`    | full TamperMonkey script to stdout        | 0    | n/a |
| `bookmarklet`   | single-line `javascript:` URL             | 0    | n/a |
| `clipboard`     | "use `copy <key>`" hint                   | 0    | ✓ surfaces tool name |
| `speak`         | `key: value` lines                        | 0    | n/a |

**Property:** every tier exits 0 with informative output. No tier
silently fails. No tier swallows the question.

## Strengths

- **TUI is the default surface.** No subcommand needed for first-time
  users; `atsisbroken` alone drops them into a labelled, navigable
  three-tab view.
- **Strategy ladder fail-down**, not fail-closed. Users in locked-down
  environments still get *some* leverage (clipboard or speak).
- **Footer keybind hints always visible.** No "press `?` for help"
  hidden affordance.
- **Schema pinned at the JSON byte level.** A user's
  `~/.atsisbroken/feedback.jsonl` from today loads cleanly tomorrow.
- **First-run detection** — `status` says "not initialized — run
  `atsisbroken init`" rather than presenting an empty profile.
- **No mouse.** Works under tmux, over SSH, on bare TTY.
- **Empty-queue and uninitialized-profile** both have explicit copy,
  not blank panes.
- **Three input vocabularies for navigation** (digits, arrows, vim).
  Whatever muscle memory the user has, atsisbroken matches it.
